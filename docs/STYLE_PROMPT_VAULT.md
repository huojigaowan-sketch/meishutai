# 风格提示词库

## 核心原则

风格参考图和提示词必须成对保存：

```text
参考图（可选但强烈推荐）
+ 用户提供的精确提示词
+ 标题 / 分类 / 标签 / 备注
= 一张风格卡
```

用户提示词默认 `isPromptLocked = true`。锁定表示大模型只能在当前生图计划中引用，不能静默修改风格卡原文。

## 为什么不自动“反推风格提示词”

单张图片无法唯一确定作者使用的模型、LoRA、采样器、后期流程和精确语义。自动反推可以作为草稿，但不能替代用户提供的准确提示词。因此 2.0 版本把用户上传的提示词视为权威数据。

## 内置模板

内置模板只包含项目需求中的操作指令，不携带第三方图片：

1. 材质 / 构图 / 元素审阅；
2. 十人同服装角色队列；
3. AO 白模严格复刻；
4. 白模材质回绘；
5. 场景减噪 30%；
6. 指定机位重构；
7. 场景镜头反打。

这些是“操作模板”，不是完整视觉风格。实际项目应再叠加用户自己的风格卡。

## 图像与许可

- 应上传用户自有、已授权或许可明确的参考图；
- 不从 GitHub 仓库自动搬运来源不明的图片；
- 若未来引入公共模板包，必须随包保存来源、许可和作者信息；
- 删除风格卡不会自动修改已经生成的历史提示词和图片记录。

## 风格卡如何参与生图

风格卡与已确认资产共同生成 `ArtPromptPlan`：

```text
资产锁定事实
+ 原文证据
+ 风格卡提示词
+ 参考图
+ 生成模式
+ 用户补充要求
→ 材质 / 构图 / 元素 / 光影
→ 正向提示词 / 负向提示词
→ 用户审阅
→ Ark 生图
```

## 推荐分类

- 通用风格
- 人物
- 服装
- 场景
- 道具
- AO 白模
- 材质回绘
- 机位与反打
- 场景减噪

## 高一致性建议

- 角色服装：参考图 + 锁定服装结构、颜色、面料、配件和磨损状态；
- 场景反打：参考图 + 锁定空间拓扑、光源方向、门窗和主要物品；
- 白模：先锁定轮廓、比例、镜头和姿态，再禁止新增颜色；
- 回绘：同时提供原图和白模，明确只改色彩、材质、纹理与光影；
- 批量人物：明确相同项和变化项，避免模型同时改变服装。
