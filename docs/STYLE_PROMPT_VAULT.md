# 风格提示词储藏室

## 数据契约

每张风格卡将用户提供的视觉参考与精确提示词作为一个不可分割的资产：

```text
标题
分类
精确提示词
参考图
标签
备注
提示词锁定状态
Apple Vision feature print
```

模型可以组合风格卡，但不能静默改写用户提示词的意义。

## Apple Vision 自动查重

上传参考图时：

```text
图片 Data
  → GenerateImageFeaturePrintRequest
  → FeaturePrintObservation
  → 与现有参考图计算 distance(to:)
```

距离极低时直接复用已有风格卡，避免重复卡片和重复图像占用。图像不上传到第三方服务完成查重。

## 自动匹配

如果用户没有手动选择风格卡，系统按以下优先级自动选择最多三张：

- 人物：人物、服装、通用；
- 场景：场景、通用、机位；
- 道具：道具、通用；
- AO 白模：白模、通用；
- 材质回绘：回绘、通用；
- 镜头反打/指定机位：机位、场景、通用；
- 场景减噪：减噪、场景、通用；
- 十人队列：服装、人物、通用。

用户选择的卡片始终优先于自动推荐。

## 内置模板

内置模板只包含项目自己的操作约束：

- 材质 / 构图 / 元素分析；
- 十人同服装队列；
- AO 白模严格复刻；
- 白模材质回绘；
- 场景减噪 30%；
- 指定机位；
- 镜头反打。

不自动复制 GitHub 或互联网中许可不明的参考图。用户应上传自己有权使用的图片。

## 持久化

```text
Application Support/MeishutaiV2/
  workspace-v2.json
  style-images/
  generated-images/
```

风格图片、提示词和生成历史均在本机。API Key 只进入 Keychain。

## 生图计划

```text
自动通过资产
  + 锁定风格卡
  + 生成模式
  + 用户补充方向
  → AppleSchemaPromptPlan
```

计划包含：主体、材质、构图、元素、光影、正向提示词、负向提示词、锁定事实和选择理由。生成按钮可以直接自动规划并调用 Ark，不要求用户先审阅提示词。
