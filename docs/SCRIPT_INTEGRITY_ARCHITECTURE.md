# 剧本完整性与 DeepSeek 提取架构

## 目标

系统的完整性目标不是“模型大概读过”，而是“任何未验证的结果都不能被标记成功”。原剧本始终是不可变的权威数据；模型结果只是带来源和状态的派生数据。

## 强制不变式

1. **导入不降级**：只接受能严格往返的 UTF-8/16/32、GB18030 或 Big5 解码。不可解码、超过 128 MB 或发生 I/O 问题时明确拒绝，不做替换字符或部分导入。文件开头 BOM 作为编码签名处理，正文中的 `U+FEFF` 保留。
2. **分集可逆**：分集只建立原字符串的连续范围视图；不 trim、不改换行、不删“第 X 章”、不清理控制字符。保存前必须满足 `parts.joined() == source`。重复或回跳集号保守地不拆，并阻止调用模型。
3. **来源绑定**：每集用 SHA-256 指纹绑定原文；每个分段和 source unit 的 ID 由指纹、字符偏移和原文确定性生成。剧本改动后，旧 checkpoint 不可复用。
4. **覆盖回执**：每段请求都必须返回正确的 `segmentID` 和全部 `coveredSourceUnitIDs`，且每个 ID 恰好一次。缺失、重复、未知 ID 或结构错误均不接受。
5. **独立覆盖审计**：抽取成功后，第二个独立审计请求重读相同 source units，对照精简资产清单查缺。最多两轮定向补抽和复审；仍有缺失时整段失败，不写入完成 checkpoint。
6. **分段事务**：通过审计的每段立即持久化。应用退出、网络失败或后续分段失败都不会删除已完成段；重试仅复用与当前指纹和分段计划完全相符的 checkpoint。
7. **终态严格**：仅接受 `finish_reason == stop`。`length`、内容过滤、系统资源不足、空 choices 和非法 envelope 都有独立错误类型。HTTP 429/5xx 和可恢复网络错误使用有界指数退避，并尊重 `Retry-After`。
8. **跨集一致**：批处理按剧情顺序逐集执行。上一集成功落盘并重建全局目录后，下一集才启动。Canonical 目录稳定排序且不做 `prefix` 截断。
9. **宁可少合并**：去重键保留标点、emoji、变音符和连续性状态。场景区分地点、时间、天气、季节、时代和类型；人物/道具区分年龄、伪装、伤损、损坏等状态。摘要按来源顺序保留所有互补唯一行。
10. **导出不反向修改数据**：重复 UUID 不得导致崩溃，所有资产行均保留。XML 1.0 非法标量只在 XLSX 导出副本中过滤，不回写剧本或工作区。

## 处理流程

```text
严格解码 -> 不可变原文 -> 可逆分集 -> SHA-256
    -> 6000 字符可逆分段 -> 750 字符 source units
    -> 严格 JSON + ID 覆盖回执
    -> 独立审计 -> 定向补抽 -> 复审
    -> 分段 checkpoint 原子落盘
    -> 集内别名整理 -> 保守本地去重
    -> 分集状态 completed / completedWithWarnings / failed
    -> 更新完整 canonical 目录 -> 下一集
```

## 可观测与恢复

每个 checkpoint 保存 request ID、model、`finish_reason`、创建时间、system fingerprint、prompt/completion/total tokens、cache hit/miss tokens 和尝试次数。警告和 `completedWithWarnings` 状态必须往返持久化，不得在重启时归零。Checkpoint 损坏时只忽略该 checkpoint 并产生恢复警告，不清空剧本、已提取资产或其他状态。

## 失败语义

“零静默丢失”可以由软件强制：原文保留、范围可逆、ID 覆盖可验证、未通过审计则失败。但任何大语言模型都不能对“每个隐含的美术资产语义必然被识别”给出数学证明。因此本架构的产品承诺是：没有验证就没有成功；失败可恢复、可定位、不污染原数据；最终导出前仍保留人工复核状态。

## 验证基线

- 原文守恒：CRLF、首尾空白、NUL、零宽字符、emoji、Markdown/JSON 干扰、章节标记。
- 分集异常：目录噪声、重复集号、回跳场号、全角/中文数字和 72 集 sentinel 恰好一次。
- 传输异常：429 + `Retry-After`、`finish_reason=length`、严格 coverage、checkpoint Codable 往返。
- 数据完整性：警告/checkpoint 往返、摘要幂等、保守合并、重复 UUID 导出、XML 非法标量。
- 发布：完整 Xcode 测试通过后才构建；新 App 先复制到同卷临时路径并校验签名/包 ID，再原子换位。换位或验证失败时恢复旧版。
