# 自动提取准确性契约

## 产品承诺

美术台不要求用户逐项审阅场景、人物和道具。系统把候选分成“生产可用”和“自动隔离”，并保证隔离候选不会进入导出、生图和后续生产。

这不是对大语言模型“永不漏项”的数学保证，而是一组软件可强制执行的不变式：没有完整覆盖、合法 Schema、逐字证据和自动核验，就没有生产入库。

## 硬性不变式

1. 原始剧本不可被模型覆盖。
2. 每个非空段落有稳定 SourceUnit ID 与范围。
3. 标准化结果必须无重复、无未知地覆盖全部 ID。
4. Final Draft/Fountain 由本地确定性渲染；FDX XML 不由模型自由书写。
5. 每个模型资产必须引用当前场景逐字子串。
6. `Scene Heading` 与 `Character` 元素的确定性结果优先于模型猜测。
7. Apple Foundation Models、content tagging、Natural Language 和可选远程模型共用同一 Apple `GenerationSchema`。
8. 自动通过资产进入生产库；隔离或拒绝资产不可导出、不可选中生图。
9. 隔离状态不制造人工任务，不阻塞其他场景继续处理。
10. 重试、网络失败或模型不可用不得删除原文、上次成功标准稿和已完成场景结果。

## 自动决策

```text
确定性 Scene Heading / Character
  → 自动通过

模型候选
  → Apple Schema 解码
  → evidence 当前场景逐字校验
  → 字段完整度
  → 多引擎共识
  → Natural Language 支持
  → 自动通过 / 自动隔离 / 自动排除
```

基础评分：

```text
35% 模型置信度
28% 逐字证据质量
17% Schema 字段完整度
15% 多引擎共识
 5% Natural Language 支持
```

模型自报置信度不能单独决定生产入库。

## 保守归并

- 同一规范键可自动归并；
- 明确别名可自动归并；
- `NLEmbedding` 距离极低时可作为补充信号；
- 不同伤损、伪装、年龄、服装或道具损坏状态默认不合并；
- 同名但证据不足的身份默认分开。

原则：宁可保留重复项，也不错误合并生产身份。

## 批量完成语义

一集或整部剧本完成不要求隔离候选归零。完成条件是：

```text
标准化覆盖完整
+
所有标准场景均已执行提取
+
生产资产库至少包含一个可用资产
+
隔离候选已从生产路径排除
```

## 观测指标

系统保留：

- 自动通过、隔离和拒绝数量；
- 使用的引擎；
- 总耗时；
- 每项 evidence；
- 多引擎一致性；
- Schema 完整度；
- Natural Language 支持；
- 自动决策理由。

这些指标用于回归测试和改进，不要求用户逐项操作。
